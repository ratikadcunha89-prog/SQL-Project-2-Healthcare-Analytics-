## Healthcare Analytics – SQL Project

This project explores hospital operations through six interconnected tables covering patients, doctors, departments, appointments, bills and medications.

### Key Objectives
- Analyse patient demographics and geographical distribution.
- Evaluate doctors' experience, workload and revenue generation.
- Identify the top five revenue-generating departments.
- Analyse billing patterns and payment methods.
- Rank patients based on medical expenditure across cities.
- Automate billing discounts using SQL triggers.
- Maintain data integrity using primary and foreign keys.

### Technical Skills Demonstrated
MySQL Workbench, Joins, Subqueries, CTEs, Window Functions, DENSE_RANK(), Views, Triggers, Aggregate Functions, Indexes, Constraints, DDL and DML.

### Project Outcome
Demonstrates the practical application of SQL in transforming healthcare data into meaningful operational and financial insights, supporting informed decision-making and efficient hospital management.
